# 三鼎學霸 (TrioBoost) - 高二語數英提分助手

一款專為高中二年級學生設計的**國文、數學、英文**衝刺提分 APP。

---

## 💡 主要功能

1. **三科分開面板**：國文、數學（數A/數B）、英文獨立專區，學習不混亂。
2. **15 題逐題計時測驗**：
   - 每次只出一題，答完上一題才會出現下一題。
   - **數學**：每題 5～10 分鐘（10 分鐘難題附有思維提示）。
   - **英文 / 國文**：每題 3 分鐘精準倒數。
   - 45 題題目完全不同，切合高二段考與學測重點。
3. **即時解析與錯題本**：
   - 答完立刻看正誤，附完整步驟、失分陷阱與秒殺技巧。
   - 做錯的題目可一鍵存入「個人錯題本」方便考前複習。

---

## 🚀 快速開始

```bash
# 1. 下載並安裝套件
npm install

# 2. 啟動 APP
npm run dev
```

開啟瀏覽器前往 `http://localhost:3000` 即可開始練習！
