# 智學三絕 · 語數英高效提分學院 (ThinkShift-G11)

一款專為高中二年級學生設計的**國文、數學（數A/數B）、英文**衝刺提分 Web 應用程式。

🌐 **GitHub Pages 線上直接體驗**：[https://410331-guyubo.github.io/ThinkShift-G11/](https://410331-guyubo.github.io/ThinkShift-G11/)

---

## 💡 主要功能

1. **全新專區 · 智學三絕**：
   - **文思絕（國文）**：古文十五篇思辨架構法、國寫情意知性立意昇華。
   - **數理絕（數學）**：向量正射影幾何直觀、二次函數區間極值防踩雷。
   - **語境絕（英文）**：大考克漏字搭配詞庫、否定倒裝與分詞構句降維。
   - **現場實測**：語數英三絕過關試煉，答錯一鍵收錄錯題本。
2. **三科獨立練習面板**：國文、數學（數A/數B）、英文專科專區，清晰分明。
3. **15 題逐題計時測驗**：
   - 每次只出一題，答完上一題才會出現下一題。
   - **數學**：每題 5～10 分鐘（難題附思維提示）。
   - **英文 / 國文**：每題 3 分鐘精準倒數。
4. **即時解析與個人錯題本**：
   - 答完立刻看正誤，附完整步驟、失分陷阱與秒殺技巧。
   - 做錯的題目可一鍵存入「個人錯題本」方便考前複習。

---

## 🚀 快速開始

```bash
# 1. 下載並安裝套件
npm install --legacy-peer-deps

# 2. 啟動本機開發伺服器
npm run dev
```

開啟瀏覽器前往 `http://localhost:3000` 即可開始練習！
